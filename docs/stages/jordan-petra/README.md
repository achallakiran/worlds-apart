# Jordan — Rose City of Petra (`jordan-petra-treasury`)

Added 9 Nov 2026 on request, outside the refactor plan (which lists no new stages). Built to the same rules as the existing sceneries.

- Source: `src/stages/jordan/petra/stage.js` (readable) and `music.mp3` (original, generated by `tools/stages/make_petra_music.py`).
- Build: `tools/stages/build_release.sh` injects the stage and track into the untouched legacy bundle (`legacy/`) and writes `release/offline/Worlds-Apart-Offline.html` plus the root `index.html`. This is a bridge; the Phase 4/5 stage-package migration replaces it.
- Registration points patched in the bundle: stage list, country list (Jordan, music track 10, threshold 0), scenery selection entry with opening cameras, embedded music array. Builder alias 11, profile 11.
- References used: Treasury (Al-Khazneh) and the Siq, Royal Tombs, Monastery (Ad-Deir), Roman theatre, plus the blocky sandstone market look of the Minecraft reference.
